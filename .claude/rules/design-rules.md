# デザインルール

AI が生成したスライドに見えないための規約。一般的なデザイン原則ではなく、このリポジトリで実際に判断した事項だけを書く。

- **面を塗らない**。角の内側まで色が乗った矩形は生成物に見える。塗ってよいのはスライド全面のバンド (`section` / `closing` / `callout` / `content-dark-code`)、ボタン (`.cta`)、最上位の強調 (`.box-strong`) のみ。カード・パネルは背景を持たせない。
- **区切りは罫線の太さで3段階**。弱 `--sb-rule-hair` / 中 `--sb-rule-accent` / 強 `--sb-rule-heavy`。色の濃さで段階を作ると弱い側が薄い塗りになる。
- **角丸は使わない**。例外はバッジとボタンの `--sb-radius-pill` のみ。
- **影を使わない**。浮かせて階層を作らない。
- **罫線は版面の下端まで通す**。カードの `min-height` で高さを埋めない。列を `align-self: stretch` で伸ばし、上下の罫線で領域を確定させる。
- **意味のない差別化をしない**。3列目だけ濃色にする類は禁止。色や太さを変えるのは Before/After のように内容に差があるときだけ。
- **番号を丸バッジにしない**。数字はタイポグラフィの大きさで順序を示す。
- **埋まらないなら余白のままにする**。囲みを足して面積を稼がない。
- **図版にも同じルールを適用する**。`images/*.svg` の角丸塗り矩形は CSS を直しても残る。行の区切りは線、状態の強調は短い縦バーで示す。
- **ゴールドは特典・表彰の文脈のみ**。汎用アクセントに使わない。
