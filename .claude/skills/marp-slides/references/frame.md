# 資料の骨格と一文の主張

始まり・終わり・章の切り替えと、一文だけを残すスライド。

| 型 | 使う場面 |
| --- | --- |
| [`title`](#title) | 表紙 |
| [`section`](#section) | 章の区切り |
| [`agenda`](#agenda) | 目次 |
| [`summary`](#summary) | まとめ |
| [`closing`](#closing) | 結び |
| [`content-center`](#content-center) | 中央に一文 |
| [`quote`](#quote) | 引用 |
| [`qa`](#qa) | 質疑応答 |

---

## title

表紙。題名と、この資料で何を扱うかを最初に伝える。

題名、短い説明、発表者・日付の順に置く。背景画像を使う場合も題名が読める余白を残す。`badge` は分類名を短く添えたいときだけ。ページ番号はこの型では表示されない。

```markdown
<!-- _class: title -->

<div class="badge">STORE EXPERIENCE 2026</div>

# 店舗体験リニューアル計画

## 「もう一つの居場所」をデジタルでも届ける

### 商品開発部 / 店舗運営部 合同提案

2026-08-08 / 社内提案レビュー
```

## section

章の区切り。話題を大きく切り替える。

章の題名と短い説明だけを置き、章の中身をここに詰め込まない。全面が塗られるため、直前と直後の明るさの差が切り替えの合図になる。

```markdown
<!-- _class: section -->

# いま店舗で起きていること

## 数字が示す3つのボトルネック
```

## agenda

目次。資料全体の順番を先に知らせる。

項目は短い名詞句に揃える。5 項目を超えると覚えられないので、章をまとめる。

```markdown
<!-- _class: agenda -->

## 本日のアジェンダ

1. いま店舗で起きていること
2. 体験設計の3つの原則
3. モバイルオーダーの改善
4. リワードプログラムの再設計
5. 導入ロードマップと成果指標

<p class="caption">各章の最後に判断してほしい点をまとめます。</p>
```

## summary

まとめ。本文で扱った要点を 3 つ程度に回収する。

各項目は「結論」の見出しと一文の説明にする。新しい情報をここで出すと、聞き手は前に戻れない。

```markdown
<!-- _class: summary -->

## 今日の要点

<div class="summary-items">

<div class="summary-item">

### 目的に合わせて選ぶ
一文、比較、手順、画像で型を変えます。

</div>

<div class="summary-item">

### 一枚一役にする
一枚の中で主張と補足を混ぜません。

</div>

<div class="summary-item">

### 次の行動を渡す
読み終えた人が動ける言葉で結びます。

</div>

</div>
```

## closing

結び。最後に渡す言葉と次の行動。

表紙より短くする。ページ番号はこの型では表示されない。

```markdown
<!-- _class: closing -->

# 小さく試し、確かめて広げる

ご質問を受け付けます。
```

## content-center

一文だけを記憶に残す。

見出しを中央に置き、説明は `caption` で一文まで。数値や比較を同じスライドに混ぜると、どちらも残らない。

```markdown
<!-- _class: content-center -->

## 迷う時間を減らすと、受け取りは速くなる

<p class="caption">案内を先に示し、利用者の判断を助けます。</p>
```

## quote

引用。調査結果の一文、利用者の言葉、判断の原則を残す。

出典を必ず添える。本文の一部を引いて説明を続けるだけなら、通常の本文スライドの `>` で足りる。

```markdown
<!-- _class: quote -->

<blockquote>
確かめて戻れる速さが、継続的な改善をつくる。
</blockquote>

<p class="quote-source">利用者インタビュー / 2026年8月</p>
```

## qa

質疑応答。発表から対話へ切り替える。

質問は一つだけ置く。説明を続けるスライドには使わない。

```markdown
<!-- _class: qa -->

<div class="qa-mark">Q&A</div>

## ここまでで気になる点はありますか

<div class="qa-prompt">具体的な状況に合わせて考えます。</div>
```
